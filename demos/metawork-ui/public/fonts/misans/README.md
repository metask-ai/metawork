# MiSans font attribution

This demo uses MiSans, provided by Xiaomi.

- Official source: https://hyperos.mi.com/font/zh/download/
- Official download: https://hyperos.mi.com/font-download/MiSans.zip
- License: MiSans-LICENSE.pdf (unmodified official copy)

The included WOFF2 files are copied unmodified from the official package. No subsetting, conversion, glyph editing or font renaming was performed. The existing UI CSS weights select Regular (400), Medium (500) and Semibold (600). Code blocks retain the existing monospace family.

SOURCE.json records original archive entries, sizes and SHA-256 hashes. These fonts are bundled as part of the MetaWork UI demo, not offered as a standalone font distribution.
