# MetaWork UI Demo

独立的 React / Vite 前端交互原型，用于讨论和迭代 MetaWork 的视觉与交互。此目录以 MetaWork 0.2.7 Renderer 为基础，包含截至 2026-10-29 已确认的 demo 修改；未接入正式 Native、AgentCore 或应用数据。

本目录独立安装、启动和构建。仓库原有 `frontend/`、`src/`、根构建配置及生产 UI 规范均未修改，也没有将此 demo 接入主程序。这里的模拟状态不代表发布版功能已修复。

## 启动

需要 Node.js 22.16 或更高的受支持版本。

```bash
cd demos/metawork-ui
npm ci
npm run dev -- --host 127.0.0.1 --port 5176 --strictPort
```

浏览器打开 <http://127.0.0.1:5176/>。

```bash
npm run check
npm run test:uiux
npm run build
npm run test:sites
```

构建输出位于 `dist/client/`；构建脚本同时保留独立静态托管所需的 worker 和配置。本提交不部署网站。

## 当前设计

- MiSans 自托管字体：正文与辅助标签 400、名称和轻强调 500、页面标题 600；回复标题适度强调，代码保留等宽字体。
- 中性浅色工作台，灰紫选中 `#F0EEF3`、悬停 `#F4F3F6`，约 5% 品牌紫点缀。无选中描边、紫色竖线或整高调宽黑线。
- 导航、项目名称和任务文字共用对齐线；归档状态使用文字标签，恢复采用带向上箭头的图标；快捷操作提供悬停与键盘提示。
- 回复正文和交付成果优先；执行过程默认折叠，错误与待审批始终明显。
- 交付文件卡片更轻、更紧凑；点击文件名打开右侧预览，“继续修改”为轻按钮。
- 首页仅保留标题和输入区；移除顶部重复“新建任务”及标题下方说明图标，保留侧栏入口与 Ctrl/⌘N。
- 工作区选择位于输入框工具栏；添加、取消选择均保留草稿。

## 可以体验

- 新建任务、模型/审批模式/工作区选择、模拟流式回复、停止和继续追问；输入“演示审批”或“演示失败”可查看对应状态。
- 项目与任务导航、搜索、重命名、归档与恢复，左右侧栏调宽。
- 回复排版、交付文件预览、源码/差异查看、执行详情。
- 技能搜索、启停、模拟导入与详情；MCP 添加、编辑、工具权限和模拟连接测试。
- 定时任务创建、编辑、暂停/恢复、手动触发及模拟历史；设置与中英文切换。

附加合成用例位于 `http://127.0.0.1:5176/?qa=uiux`，用于长会话、双工具执行及调度原因的界面检查。普通入口仍为原始三任务示例。

## 能力边界

全部任务、账号、模型、服务与工作区为合成数据。真实模型、MCP、系统凭据、后台定时器、原生文件操作和已安装 MetaWork 的存储均未接入。工作区添加只创建 `/Demo/名称` 元数据，不创建本机目录；技能导入使用内置样本。密钥表单只用于交互演示，不保存或发送输入值。

刷新恢复初始演示数据；语言、面板等浏览器偏好保存在当前来源的 localStorage。生产产品的规范仍以仓库 `docs/` 为准，不能把原型表现当作真实能力或平台验收。

此提交不含本地 QA 记录、私人截图、开发缓存、依赖目录或构建产物。
